## 2. What was wrong with the prior engines

- **`nq_cond_be45.py` / SAL-only engine (PF 1.678, net +15,665, 1,256 trades,
  status: RETRACTED for deployable execution):** each level's touch is
  evaluated independently. Two levels can each be "first touched" while the
  other's resulting trade is still open, and SAL only blocks new *entries*
  after a *realized* loss — it does not enforce a single global position and
  does not reason about exit timestamps causally. Concurrent winners are
  legal in this engine. This engine remains valid as the *candidate
  population generator* (gate 1) but not as a P&L simulator.
- **A prior "genuinely single-position" claim (PF ~1.2-1.4, net ~+3,918,
  3,093 trades) could not be reproduced** because it was built without
  access to the real `volgen.reactions._first_touch` and used a different,
  non-matching touch-detection / candidate population. Status: **FAILED
  REPRODUCTION** — the 3,093 trade count is inconsistent with the 1,841
  eligible-candidate gate under any of the edge-case orderings tested here
  (all strict variants land between 1,104 and 1,109 executed trades).

## 3. Strict engine architecture

Chronological, single-pass state machine over every level-side's **physical
first touch** (at most one touch per level-side, ever — a level is
permanently consumed once touched or once expired, whichever comes first).

- Exactly one active NQ position globally.
- Entries only accepted 19:00-11:00 ET; a touch inside 11:00-15:00 ET
  consumes the level (`skipped_blocked_time`).
- A touch while a position is open consumes the level (`skipped_position_open`).
- A touch while SAL is active consumes the level (`skipped_SAL`).
- SAL arms at the **actual exit timestamp** of a realized loss (pnl < 0,
  exit != BE), not at entry, and resets at the next 19:00-15:00 session.
- Risk: `anchor` = previous completed 60-minute range at touch time;
  `cap = min(1.5*anchor, 200)`; TP = SL = cap; conditional BE at 45 bars,
  identical to `nq_cond_be45.simulate_cond_be`.

## 4. Six edge cases — primary rule + individually-tested sensitivity

| Edge case | Primary (conservative) rule | Effect vs primary |
|---|---|---|
| A. Creation-bar touches | No entry on the level's creation bar; touch search starts on the next bar | 0 touches in the whole dataset ever landed exactly on a creation bar — **no effect** |
| B. Touch-bar TP/SL | On the touch bar, only the stop is checked; a target hit on the touch bar is not assumed a win | net +6,648.2 -> **+6,794.0** if touch-bar wins are assumed (skip-touch-bar / original behavior) |
| C. Gap-through fills | If the touch bar's high-low range doesn't actually contain the level, fill at the bar's close, not the level | 8 gap-through entries across 2018-2026; adjusting for realistic fill vs assuming level-fill changes net by **+146.6 pts** (net would be 6,421.3 pts without the adjustment) |
| D. Same-bar exit/re-entry | No new entry on the same 1-minute bar the active trade exits | 7 attempts blocked; allowing them changes net to **+6,629.4** |
| E. Simultaneous touches | Deterministic level-age ordering (older level wins ties) | 77 simultaneous groups, 94 losing sides. Nearest-to-prior-close: net 6,540.6. Farthest-first: net 7,290.6. Conservative-worst-result: net 6,540.6 |
| F. Expiry timestamp | Exclude the expiry timestamp bar itself from the touch search | 0 touches in the dataset ever fell exactly on an expiry timestamp — **no effect** |

Full per-config table: `outputs/nq_edge_case_sensitivities.csv`.

## 6. Answers to the required final-response questions

1. **Did the 1,841 gate pass?** Yes — exact match.
2. **Was the prior strict result (PF ~1.2-1.4, net ~+3,918, 3,093 trades)
   recovered?** No — status **FAILED REPRODUCTION**. The rebuilt strict
   engine, built directly from `volgen.reactions._first_touch` and the
   1,841-candidate gate, produces 1,107 executed trades (not 3,093) and net
   +6,648 pts (not +3,918). The 3,093-trade version was very likely built
   against a longer or unbounded touch-search window (no `LINE_DAYS`

     enforcement; SAL blocks entries but not overlap between two winners.
   - The unreproduced "3,093-trade" engine: touch-detection / candidate
     population inconsistent with the 1,841 gate; not built from the
     canonical `_first_touch`/`LINE_DAYS` architecture.
4. **Fully conservative final result:** net **+6,648.17 pts**, PF **1.2924**,
   tWR 54.2%, max DD -1,290.29, 1,107 trades, 2018-2026.
